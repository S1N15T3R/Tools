# Personal Tools

A collection of personal utility scripts, automation workflows, and security tools.

## Tools

- [**bugbounty_program_extract-bot**](./bugbounty_program_extract-bot/): Automated bug bounty program extractor and IDOR reconnaissance tool for HackerOne, Bugcrowd, and YesWeHack.
- [**server-backup**](./server-backup/): Automated multi-cloud and local server backup script with support for S3, B2, Wasabi, and Google Drive.
